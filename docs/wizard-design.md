# BOOK IT 위저드 디자인 기준

2026-10-26 사용자 검토 결과를 기준으로 한다. 적용 범위는 `/apply/design-preview`이며 기존 `/apply`의 디자인을 교체하지 않는다. 이 문서가 BOOK IT 미리보기의 이전 누적 디자인 메모보다 우선한다.

## 지정 계층

| 책임 | 정본 |
| --- | --- |
| 전역 색상 원형 | `src/app/globals.css`의 기존 Neutral 및 상태 변수 |
| 위저드 역할별 색상·모서리·간격·제목 | `src/components/wizard/WizardDesign.module.css`의 `.theme` |
| 레이아웃·입력·선택·반복 행 | `src/components/wizard/BookingPreview.module.css` |
| 공통 제목 | `StepHeading.tsx`, `data-step-heading` |
| 반복 입력 구조·검증 속성 전달 | `BookingPreviewForms.tsx`의 `PreviewRepeatRow` |
| 일정 상태 전환과 완료 조건 | `bookingPreviewScheduleState.ts` |
| 제목 등 편집 가능한 기본 문구 | `bookingPreviewData.ts` |

`BookingPreview` 루트에서 테마를 한 번 적용한다. 개별 페이지에서 같은 색상·반경·제목 스타일을 재지정하지 않는다. 새로운 요소는 역할별 토큰과 공통 컴포넌트를 먼저 확장한다.

## 입력과 묶음

- `data-input-group`으로 의미상 묶음을 지정한다. 묶음은 group 배경과 공통 padding, 반복 행은 surface 배경과 record gap을 쓴다.
- 입력 크기는 기존 `data-field-size`/공통 short·medium·long 규격을 사용한다. 페이지별 임의 너비 대신 데이터 의미에 맞는 규격을 선택한다.
- `data-field-key`, 접근성 이름 및 오류 위치 식별자를 유지한다. 미리보기 반복 행은 운영 화면의 inline grid 스타일을 가져오지 않는다.
- 자동 계산값은 `data-auto-value` 규칙과 readonly 배경으로 표시한다. 입력창처럼 흰색으로 표현하지 않는다.
- 일정의 고정 정보는 위쪽 2열, 수정 가능한 요청시간·철수시간·티켓오픈일은 아래쪽 3열이다. 좁은 화면에서는 공통 반응형 규칙에 따라 줄바꿈한다.
- 티켓 가격 단위와 삭제 버튼은 해당 반복 행에 속한다. 프로모션 입력도 같은 행 라이브러리를 사용한다.

## 선택과 제목

- 시설 버튼은 hover에서 기존 1px 경계선 색만 검정으로 바꾼다. 추가 outline이나 두꺼운 ring을 만들지 않는다.
- 테두리가 있는 체크 선택 칩도 기존 경계선만 바꾼다. 선택 칩은 검정 배경으로 표시한다.
- 일반 체크 행과 내부 native checkbox에 별도의 hover 외곽선을 추가하지 않는다. 키보드 포커스는 유지한다.
- 단계 제목은 공통 제목 크기·행간·간격을 사용한다. 선택된 탭의 선과 접힌 아코디언 구분선은 공통 CSS에서 관리한다.

## 의도적으로 남기는 차이

- 달력 날짜 상태, 수량 조절, 서명, 파일 첨부의 기능적 구조는 일반 텍스트 입력과 다르므로 전용 규칙을 유지한다.
- 운영 화면의 담당자 열 수에 따른 `gridTemplateColumns`는 데이터 기반 구조이다. 미리보기에서는 제거하고 공통 반복 행으로 렌더링한다.
- 2열·3열 배치는 정보 구조이며 모든 요소를 같은 열 수로 강제하지 않는다.
- 기존 달력의 역할 색상 및 상태 표현은 유지한다. 새 색상 팔레트나 전역 디자인 교체를 이 작업에 포함하지 않는다.
- 데이터 형식과 실제 신청 경로는 유지한다. 공통 API·요금 계산의 오류 수정은 운영 경로에도 적용된다.

## 검증 기준

데스크톱과 모바일에서 반복 행·제목·읽기 전용 값·가로 넘침을 확인한다. 일정 변경은 실제 요금 계산기 및 생성/수정 API 회귀 테스트로 검증한다. 미리보기의 로컬 제출 성공은 실제 DB 저장·첨부·알림의 통합 검증을 대신하지 않는다.
